# bioinformatics-journey
My self-taught path into clinical/genomics bioinformatics

## About me
Biotechnology and Genetic Engineering graduate with a strong interest in human genetics and variant interpretation. Author of a published case report on an *EDA* gene variant in X-linked hypohidrotic ectodermal dysplasia (XLHED), where I worked hands-on with Sanger sequencing, pedigree analysis, and variant classification (ClinVar, gnomAD, ACMG).
I'm now building practical bioinformatics skills to move into clinical/genomics analysis.

## what's in this repo
A running log of my learning — scripts, exercises, and small projects as I work through:
- **Comand line & tooling** — Unix shell, Conda, Git
- **Python** — for biological data and sequence analysis
- **Data analysis** — pandas, statistics, visualization
- - **R & Bioconductor** — genomics-specific analysis
- **NGS & variant analysis** — alignment, variant calling, annotation, interpretation

## Current focus
Phase 0 — setting up the toolkit (Conda, Git, command line). 
Just getting started.
